# 中台

本机运行的决定管理系统。决定是主记录，票是挂在决定上的工作项，前提是决定能被推翻的依据。

## 语言

**中台**：
本机运行的决定管理系统，替代 GitHub Issues 承载决定与票的关系。
_Avoid_: 决定板、board、决策系统

**数据目录**：
中台自己存数据的固定目录，在仓库之外。
_Avoid_: 数据仓库、存储目录

**事件日志**：
只追加的事件记录，是全部状态的权威来源。
_Avoid_: 日志文件、流水

**索引库**：
从事件日志折叠出来的查询库，删掉可以从事件日志重建。
_Avoid_: 数据库、缓存

**服务**：
本机唯一写事件日志的进程，CLI 和屏幕都通过它读写。
_Avoid_: 后端、server

**屏幕**：
浏览器里的决定图、提醒条和详情面板。
_Avoid_: 前端、界面、UI

**残片**：
崩溃时写出的一半事件行，恢复时搬走并截断。
_Avoid_: 半行、脏数据

**事件**：
事件日志里的一行，表示一次动作。
_Avoid_: 记录、日志行

**op**：
事件里的动词，说明这次动作是什么，决定按哪种 payload 结构折叠。
_Avoid_: 动作类型、命令

**payload**：
事件里装这次动作所需内容的字段。
_Avoid_: 参数、内容

**折叠**：
按事件顺序重放，算出当前状态。
_Avoid_: 重放、回放

**状态哈希**：
对折叠后的状态按固定规则算出的值，用来比对两次重建是否一致。
_Avoid_: 校验和、指纹

**本地号**：
中台自己发的实体编号，先于 GitHub 编号存在，同步后保持不变。
_Avoid_: 临时号、内部号

**因果边**：
用来算影响范围的边。包括谁产生谁、谁取代谁、谁依赖哪条前提、根决定的哪一块由哪张票落。
_Avoid_: 关系、依赖

**拆票理由**：
创建票时写下的一句话，说明这张票为什么从根决定拆出来。它是因果边的一部分。
_Avoid_: 拆票说明、创建原因

**工作状态**：
票的执行进度，如未领取、进行中、等待人、被挡。由执行侧同步到中台，不靠会话链接。
_Avoid_: 运行状态、进度

**同步日志**：
记录同步结果和 GitHub 编号映射的独立日志，不属于业务事件。
_Avoid_: 同步记录、镜像日志

**镜像**：
GitHub 上由中台写出的只读副本，不接收 GitHub 上的直接修改。
_Avoid_: 备份、同步

**actor**：
事件里表示谁做了这次动作，格式为 `human:<名字>` 或 `agent:<名字>`。
_Avoid_: 操作人、用户
