# 中台

本机运行的决定管理系统。决定是主记录，票是挂在决定上的工作项，前提是决定能被推翻的依据。

## 语言

**中台**：
本机运行的决定管理系统，替代 GitHub Issues 承载决定与票的关系。
_Avoid_: 决定板、board、决策系统

**地图**：
中台里 kind 为 map 的 issue，存终点和根决定，下面挂票。
_Avoid_: 看板、总票、路线图

**票**：
中台里 kind 为 ticket 的 issue，挂在决定上的工作项，一次会话能做完。
_Avoid_: 工单、任务

**决定**：
中台的主记录，一句话写清定了什么。有编号，只写一次；要改就新建一条取代旧的那条。
_Avoid_: 决策、决议、决定项

**前提**：
一条决定成立所依赖的一句可被证伪的话。前提判破，决定就要重新判。
_Avoid_: 假设、条件、理由

**判定**：
人对一条前提或决定下的结论，记成一条事件。判定会改变状态，判定用的词和状态值不是一回事。前提的判定词只有 `成立`、`已破`、`未知`；决定的四档处理是 `仍成立`、`需修改`、`作废`、`要补问`。
_Avoid_: 判断、裁决

**影响清单**：
一条决定变更后，中台沿因果边算出的受影响决定和票的集合，逐项处理完才能关闭。
_Avoid_: 影响案、影响面、波及清单

**范围项**：
影响清单里的一条受影响对象，一条决定或一张票，带进入范围的原因。
_Avoid_: 影响对象、条目

**触发事件**：
打开影响清单的那条事件，决定或前提的变化写在里面。
_Avoid_: 起因、来源

**范围快照**：
影响清单打开时算出的范围，之后不随清单外变化增长。
_Avoid_: 影响范围、边界

**已失效项**：
决定在别的清单里已经变成被取代或作废，本清单里这一项不再要求处理动作。
_Avoid_: 自动关闭项、跳过项

**处理动作**：
影响清单里人对一个范围项做的处置。决定四档：仍成立、需修改、作废、要补问；票五种：保留、改范围、关掉、重开、新建。
_Avoid_: 解决方案、操作

**问题目录**：
中台推进 Map 时会遇到的问题清单，分自动发现和靠人发现两半，每项写明处理动作。
_Avoid_: 问题表、检查单

**前提状态**：
前提当前停在哪一步，四个值：`未验`、`成立`、`已破`、`未知`。`未验` 是新建还没判过，另外三个是最近一次判定的结果。
_Avoid_: 判定、结论

**根决定**：
地图终点的主句存成的决定，是一张地图决策树的起点。
_Avoid_: 总决定、目标、根节点

**拆句**：
根决定按句拆开后的片段，覆盖表按它逐句检查。
_Avoid_: 片段、子句、句子

**覆盖边**：
一张票承接根决定哪一句的边。
_Avoid_: 覆盖关系、映射

**覆盖表**：
按拆句列出承接它的票和拆票理由的视图。
_Avoid_: 覆盖清单、进度表

**数据目录**：
中台自己存数据的固定目录，在仓库之外。
_Avoid_: 数据仓库、存储目录

**事件日志**：
只追加的事件记录，是全部状态的权威来源。
_Avoid_: 日志文件、流水

**索引库**：
从事件日志折叠出来的查询库，删掉可以从事件日志重建。
_Avoid_: 数据库、缓存

**服务**：
本机唯一写事件日志的进程，CLI 和屏幕都通过它读写。
_Avoid_: 后端、server

**屏幕**：
浏览器里的决定图、提醒条和详情面板。
_Avoid_: 前端、界面、UI

**残片**：
崩溃时写出的一半事件行，恢复时搬走并截断。
_Avoid_: 半行、脏数据

**事件**：
事件日志里的一行，表示一次动作。
_Avoid_: 记录、日志行

**op**：
事件里的动词，说明这次动作是什么，决定按哪种 payload 结构折叠。
_Avoid_: 动作类型、命令

**payload**：
事件里装这次动作所需内容的字段。
_Avoid_: 参数、内容

**折叠**：
按事件顺序重放，算出当前状态。
_Avoid_: 重放、回放

**状态哈希**：
对折叠后的状态按固定规则算出的值，用来比对两次重建是否一致。
_Avoid_: 校验和、指纹

**本地号**：
中台自己发的实体编号，先于 GitHub 编号存在，同步后保持不变。导入的 issue 保留 GitHub 号，新建的才发 `I-`。
_Avoid_: 临时号、内部号

**因果边**：
用来算影响范围的边。包括谁产生谁、谁取代谁、谁从谁拆出来、谁依赖哪条前提、根决定的哪一句由哪张票接。
_Avoid_: 关系、依赖

**拆票理由**：
创建票时写下的一句话，说明这张票为什么从某条决定拆出来。它存在票上，是因果边的一部分。
_Avoid_: 拆票说明、创建原因

**票型**：
票的四种保真度：grilling、research、prototype、task。
_Avoid_: 类型、类别

**评论**：
挂在票或地图上的一段说明，有作者和时间，可编辑，可删除。
_Avoid_: 回复、留言

**无主票**：
没有来源决定的票。
_Avoid_: 孤儿票

**无源决定**：
没有来源票的决定，根决定除外。
_Avoid_: 孤儿决定

**吃旧决定**：
票还挂在已被取代或作废的决定上。
_Avoid_: 旧票、过期票

**工作状态**：
票的执行进度，如未领取、进行中、等待人、被挡。由执行侧同步到中台，不靠会话链接。
_Avoid_: 运行状态、进度

**同步日志**：
记录同步结果和 GitHub 编号映射的独立日志，不属于业务事件。
_Avoid_: 同步记录、镜像日志

**镜像**：
GitHub 上由中台写出的只读副本，不接收 GitHub 上的直接修改。
_Avoid_: 备份、同步

**导入**：
从 GitHub 读一张地图和它的票、评论、决定，写进中台。一张地图只做一次，不改 GitHub。
_Avoid_: 迁移、拉取

**同步**：
把中台的当前状态写到 GitHub 镜像。运营者按地图触发，平台执行。
_Avoid_: 推送、导出、备份

**镜像开关**：
每张地图上的开关，决定这张图是否同步到 GitHub。关掉时只在中台维护。
_Avoid_: 同步开关、发布开关

**生成段**：
同步时写进 GitHub 地图正文的一段 Markdown，由中台按当前状态生成，带标记，整段替换。
_Avoid_: 渲染段、导出块

**同步计划**：
同步前列出要新建、更新、关闭、发评论和改写生成段的清单，运营者确认后执行。
_Avoid_: 同步预览、变更单

**同步异常**：
同步失败，或 GitHub 上的内容和镜像不一致时的状态。显示在屏幕和同步日志里。
_Avoid_: 同步错误、失败状态

**未记录**：
导入的旧票缺少拆票理由等因果信息时的显示值，表示当时没记，不是没有。
_Avoid_: 未知、空

**actor**：
事件里表示谁做了这次动作，格式为 `human:<名字>` 或 `agent:<名字>`。
_Avoid_: 操作人、用户
