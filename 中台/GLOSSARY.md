# 中台

本机运行的决定管理系统。决定是主记录，票是挂在决定上的工作项，前提是决定能被推翻的依据。

## 语言

**中台**：
本机运行的决定管理系统，替代 GitHub Issues 承载决定与票的关系。
_Avoid_: 决定板、board、决策系统

**地图**：
中台里 kind 为 map 的 issue，存终点和根决定，下面挂票。
_Avoid_: 看板、总票、路线图

**票**：
中台里 kind 为 ticket 的 issue，挂在决定上的工作项，一次会话能做完。
_Avoid_: 工单、任务

**决定**：
中台的主记录，一句话写清定了什么。有编号，只写一次；要改就新建一条取代旧的那条。
_Avoid_: 决策、决议、决定项

**前提**：
一条决定成立所依赖的一句可被证伪的话。前提判破，决定就要重新判。
_Avoid_: 假设、条件、理由

**判定**：
人对一条前提或决定下的结论，记成一条事件。判定会改变状态，判定用的词和状态值不是一回事。前提的判定词只有 `成立`、`已破`、`未知`；决定的四档处理是 `仍成立`、`需修改`、`作废`、`要补问`。
_Avoid_: 判断、裁决

**前提状态**：
前提当前停在哪一步，四个值：`未验`、`成立`、`已破`、`未知`。`未验` 是新建还没判过，另外三个是最近一次判定的结果。
_Avoid_: 判定、结论

**根决定**：
地图终点的主句存成的决定，是一张地图决策树的起点。
_Avoid_: 总决定、目标、根节点

**拆句**：
根决定按句拆开后的片段，覆盖表按它逐句检查。
_Avoid_: 片段、子句、句子

**覆盖边**：
一张票承接根决定哪一句的边。
_Avoid_: 覆盖关系、映射

**覆盖表**：
按拆句列出承接它的票和拆票理由的视图。
_Avoid_: 覆盖清单、进度表

**数据目录**：
中台自己存数据的固定目录，在仓库之外。
_Avoid_: 数据仓库、存储目录

**事件日志**：
只追加的事件记录，是全部状态的权威来源。
_Avoid_: 日志文件、流水

**索引库**：
从事件日志折叠出来的查询库，删掉可以从事件日志重建。
_Avoid_: 数据库、缓存

**服务**：
本机唯一写事件日志的进程，CLI 和屏幕都通过它读写。
_Avoid_: 后端、server

**屏幕**：
浏览器里的决定图、提醒条和详情面板。
_Avoid_: 前端、界面、UI

**残片**：
崩溃时写出的一半事件行，恢复时搬走并截断。
_Avoid_: 半行、脏数据

**事件**：
事件日志里的一行，表示一次动作。
_Avoid_: 记录、日志行

**op**：
事件里的动词，说明这次动作是什么，决定按哪种 payload 结构折叠。
_Avoid_: 动作类型、命令

**payload**：
事件里装这次动作所需内容的字段。
_Avoid_: 参数、内容

**折叠**：
按事件顺序重放，算出当前状态。
_Avoid_: 重放、回放

**状态哈希**：
对折叠后的状态按固定规则算出的值，用来比对两次重建是否一致。
_Avoid_: 校验和、指纹

**本地号**：
中台自己发的实体编号，先于 GitHub 编号存在，同步后保持不变。导入的 issue 保留 GitHub 号，新建的才发 `I-`。
_Avoid_: 临时号、内部号

**因果边**：
用来算影响范围的边。包括谁产生谁、谁取代谁、谁从谁拆出来、谁依赖哪条前提、根决定的哪一句由哪张票接。
_Avoid_: 关系、依赖

**拆票理由**：
创建票时写下的一句话，说明这张票为什么从某条决定拆出来。它存在票上，是因果边的一部分。
_Avoid_: 拆票说明、创建原因

**票型**：
票的四种保真度：grilling、research、prototype、task。
_Avoid_: 类型、类别

**评论**：
挂在票或地图上的一段说明，有作者和时间，可编辑，可删除。
_Avoid_: 回复、留言

**无主票**：
没有来源决定的票。
_Avoid_: 孤儿票

**无源决定**：
没有来源票的决定，根决定除外。
_Avoid_: 孤儿决定

**吃旧决定**：
票还挂在已被取代或作废的决定上。
_Avoid_: 旧票、过期票

**工作状态**：
票的执行进度，四个值：`未领取`、`进行中`、`等待人`、`被挡`。由执行侧同步到中台，不靠会话链接。
_Avoid_: 运行状态、进度

**离线**：
orca 连不上时的全局连接状态，不是票级工作状态。
_Avoid_: 掉线、断开

**工作状态快照**：
中台存工作状态的 `workstate.json`，记每张票的当前状态、进入状态的时间、最后一次成功同步时间和离线标记。
_Avoid_: 状态缓存、工作状态日志

**worktree**：
Orca 管理的一次仓库检出，带分支、终端和 agent。中台按它判断票有没有被领取。
_Avoid_: 工作区、工作树

**同步日志**：
记录同步结果和 GitHub 编号映射的独立日志，不属于业务事件。
_Avoid_: 同步记录、镜像日志

**镜像**：
GitHub 上由中台写出的只读副本，不接收 GitHub 上的直接修改。
_Avoid_: 备份、同步

**导入**：
从 GitHub 读一张地图和它的票、评论、决定，写进中台。一张地图只做一次，不改 GitHub。
_Avoid_: 迁移、拉取

**同步**：
把中台的当前状态写到 GitHub 镜像。运营者按地图触发，平台执行。
_Avoid_: 推送、导出、备份

**镜像开关**：
每张地图上的开关，决定这张图是否同步到 GitHub。关掉时只在中台维护。
_Avoid_: 同步开关、发布开关

**生成段**：
同步时写进 GitHub 地图正文的一段 Markdown，由中台按当前状态生成，带标记，整段替换。
_Avoid_: 渲染段、导出块

**同步计划**：
同步前列出要新建、更新、关闭、发评论和改写生成段的清单，运营者确认后执行。
_Avoid_: 同步预览、变更单

**同步异常**：
同步失败，或 GitHub 上的内容和镜像不一致时的状态。显示在屏幕和同步日志里。
_Avoid_: 同步错误、失败状态

**未记录**：
导入的旧票缺少拆票理由等因果信息时的显示值，表示当时没记，不是没有。
_Avoid_: 未知、空

**actor**：
事件里表示谁做了这次动作，格式为 `human:<名字>` 或 `agent:<名字>`。
_Avoid_: 操作人、用户

## 草案：两个侧边栏的阅读层（#144 访谈结论，2026-11-11）

以下几条来自 #144 内容层和视觉层访谈，等原型验收后再定稿。它们不是新实体，是由已有记录拼出来的阅读视图；字段和事件模型不变。

**票侧边栏**：
一张票的阅读视图，回答这张票的任务。按「怎么拆出来的 → 要做什么 → 产出了什么 → 证据 → 未定」五段展开。产出决定只列 id、角色、状态，点进决定侧边栏。
_Avoid_: 票档案、决定档案、详情页

**决定侧边栏**：
一条决定的阅读视图，回答这条决定的结论和依据。开头先给决定全文，再按「前提 → 依据摘要与产出 → 决策与决策的关系 → 影响 → 对话摘录 → 未定」六段展开。只链来源票，不重复票的任务内容。
_Avoid_: 决定档案、票档案、详情页

**决策组**：
同一张票产出的决定集合：一条主决定加若干补充决定。是阅读层分组，不是实体；模型里没有父子字段。
_Avoid_: 决定族、决定树、父子决定

**组内关系**：
同一个决策组里主决定和补充决定的并列关系。补充决定按实现维度分组，能看出是并列维度还是同一件事的不同面。
_Avoid_: 子决定、派生决定

**组间关系**：
同一张地图里不同决策组之间的关系，用组级小树表示。只画读得出的边：同根、票的顺序、覆盖句。
_Avoid_: 决定依赖图、跨组依赖

**问题背景**：
这张票在问什么、为什么现在问、范围到哪。由票正文的 Question、背景、范围、验收条件加一段 agent 起草的摘要组成。
_Avoid_: 需求描述、票简介

**依据摘要**：
一条决定的依据概述，一段人话，回答「为什么这么定」。由这条决定依赖的前提合成，agent 起草，人审阅。
_Avoid_: 决定理由、结论

**来龙去脉**：
一条前提的发现过程。写清事实从哪来、怎么发现、影响了哪条决定。由对话摘录和证据指针组成，agent 起草，人审阅。
_Avoid_: 发现过程、背景

**对话摘录**：
一段关键问答，带来源指针和支撑对象。来源是 issue 评论或本地会话，agent 摘出来。对话原文不搬进中台。
_Avoid_: 聊天记录、对话全文

**顶部栏**：
屏幕顶部 44px 的常驻条，只放全局信息：品牌、地图标题、计数、视图切换、信号入口、主题开关。展开后是次级信息层，在流内推开内容，不遮挡右侧侧边栏。
_Avoid_: 导航栏、header、第二内容区

**主题**：
浅色 / 深色 / 跟随系统三档。切换不刷新，记在 `localStorage`，地址栏 `theme` 参数可分享。深色按 GitHub 深色设计语言做，颜色全部走 CSS 变量。
_Avoid_: 夜间模式、配色
