# 客户规则放 AGENTS.md，提示词只做触发

2026-11-05 决定。客户工作区根目录放一份 `AGENTS.md`，装好后每个新会话由 `dsh` 自动注入。提示词①负责装技能、写这份文件。提示词②只留触发语：「开始需求澄清」和「继续」。

为什么：常驻规则要覆盖谁管什么、两类分流、一次会话一张票、跳步怎么处理、原型被动、技术题怎么答、进度文件放哪。写进文件，客户不用每次重贴，也不会漏。

代价：`dsh` 注入时写明不覆盖客户的直接指令。客户跳步时，这份规则只能提醒，拦不住。提醒满 3 次客户仍坚持，就照做，记一笔。上下文压缩后还注不注入，没验证。
