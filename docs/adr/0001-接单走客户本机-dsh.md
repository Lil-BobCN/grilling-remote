> 2026-11-07 部分被 [客户交完之后怎么知道进度：谁、用什么方式、在哪几个节点告诉客户](https://github.com/Lil-BobCN/grilling-remote/issues/52) 和 [客户进度模块：登录、四屏样品、五档状态](https://github.com/Lil-BobCN/grilling-remote/issues/109) 取代：网站增加登录后的订单进度页，不再只放教程和提示词。上传页见 [客户本机的进度文件怎么回到我们这里](https://github.com/Lil-BobCN/grilling-remote/issues/24)。原文不改。

2026-11-05 决定。客户澄清从托管网页 agent 改成客户本机安装 DeepSeek Harness（`dsh`）。原因是网页方案没有客户登录和多租户隔离：任何拿到链接的浏览器都是 owner，能读到别的客户会话。改成本机后，客户文件不出机器，网站只放教程和提示词。代价是安装和技能包要客户自己跑，客服得带装。
