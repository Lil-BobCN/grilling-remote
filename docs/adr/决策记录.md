# 决策记录

> 状态：现行

这里收够三条标准的决定：难回退、不写会让人意外、有真实取舍。缺一条不写，留在中台。

完整决策记录在中台（`http://127.0.0.1:8788`，命令行 `中台/dt`，数据在 `~/.grilling/中台/`）。这里只是便于读工作区的子集。每条末尾有 `决定：D-xxxx`、`来源票：……`、日期和状态；有疑问，或代码和记录对不上时，按这两个指针去中台和 GitHub 查证。中台自身的实现决定写在 `中台/docs/adr/`，这里不重复。

## 怎么读

- 先看目录，按领域找到相关的几条，再读正文。
- `状态：现行` 的决定按它执行。
- `状态：被取代，见 D-xxxx` 的决定只作历史，按新决定执行。新决定不一定收在这份文件里，按 D 编号去中台查。
- 来源票写中台票号；导入的老票直接写 GitHub 编号。本地票在括号里附 GitHub 编号。
- 日期用中台记录的日期。老票的原始决定日期可能更早，按来源票查。

## 怎么加

关票时由干活的 agent 判断够不够三条标准。够的写进这里，和关票 PR 同一张；运营者合并 PR 即确认。格式见 `docs/agents/domain.md`。关票前跑 `python3 scripts/check-decisions.py`，脚本只报，不改正文。
