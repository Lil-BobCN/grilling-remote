# 父工单样例

标题用客户那句话，不改写。下面是按 `docs/工单模型.md` 的五段，从 `工作区/.scratch/xianguopu/` 读出来的。

标题：顾客想在我的微信小程序里看今天有什么水果，下单，选到店取还是送货。我在后台改价格和库存。

## 客户原话

> 「顾客想在我的微信小程序里看今天有什么水果，下单，选到店取还是送货。我在后台改价格和库存。」

日期：2026-11-08

## 客户确认的结论

- 店里贴二维码，扫进小程序看当天清单。
- 到店取的不先付，取货时付；送货的微信转账。
- 后台首页先看卖完的，改一个价格点两下。
- 取好货后在后台点一下，顾客收到微信通知。
- 推荐微信云开发，等运营者确认

## 验收条件

- [ ] 顾客扫码进小程序，看到当天水果的名单。
- [ ] 卖完的水果标灰，不能下单。
- [ ] 老板在后台改一个价格，点两下改完，顾客那边马上看到。
- [ ] 顾客下单时能选到店取或送货，送货加收 5 元。（人工判断）
- [ ] 老板点「已取货」，顾客收到微信通知。（人工判断）
