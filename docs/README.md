## 状态块怎么写

H1 后第一行写下面三种之一：

- `> 状态：现行`
- `> 状态：部分历史（第 X 节起只作历史）`
- `> 状态：历史（<日期> 被 D-xxxx 取代）`

## 包内的 15 份没有状态块

`customer-kit/package/` 是随 zip 发布的成品。里面 11 份上游技能原件按 `NOTICE.md` 的要求正文不改，整包内容由 `customer-kit/release.json` 的 SHA256 锁定，所以这 15 份不写状态块。包外 3 份照常标。
