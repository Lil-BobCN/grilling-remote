## 已确认的事实

- `dsh` 会读工作目录的 `AGENTS.md` 和 `CLAUDE.md`，第一次请求时注入，上限 64KB。目录里没有 `.git` 时，项目根就是工作目录。依据：`@deepseek-ai/dsh-agent-instructions` 的 `README.zh.md` 和 `lib/index.js:574-582`。
- 注入文本写明不覆盖用户的直接指令。所以 AGENTS.md 只能劝，拦不住。
- Wayfinder 原文：一个会话最多解一张票。地图是索引，不存细节。需要人参与的票，由人确认答案才算解决。
- 原型默认被动做：地图里有 prototype 票才做。客户想主动做，先建票再做。这是 Agent 对原文的读法。
