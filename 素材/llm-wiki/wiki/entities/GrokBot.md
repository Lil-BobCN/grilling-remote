# GrokBot

## 定义

GrokBot 是 Cursor 的 agent 产品。每个 bot 有自己的电脑、身份、头像和例行任务，可以登录你常用的工具，也能被协调 agent 分派工作。

## 来源观点

S2 的演示里，劳伦的幕僚长 agent 会联系购物 agent、营销 agent，让它更新 LinkedIn；另一个演示用 Figma Slides 整理内部反馈。她说设计灵感是「聪明的同事在聊天里」，界面像 iMessage。

S1 说 GrokBot 背后的框架做任何事只有一种方式：每个功能一个目录，lint 拦错误 import，代码注释被禁止。

S3 里，GrokBot 被当作外循环的连接器：盯 Slack、X、邮件和 Linear，把问题送进 Cursor projects。
