## 一句话摘要

Lauren 讲她从手动管一个 agent 走到每月约 2,500 个 PR 的路径：验证技能、环境约束、内外循环、抽样验收，以及可验证性的边界。

## 主要论点

- 信任阶梯：手动微管理、验证、环境、协调 agent 加多项目、agent 自己合并。
- 验证是第一个真正让她放手的 skill；早期她是 agent 和 Chrome 开发者工具之间的人肉代理。
- 把确定性步骤固化成 CLI，判断留给 agent。
- 内外循环：GrokBot 收 Slack、X、邮件的问题，Cursor projects 的协调 agent 分给 sub agent。
- 多个 agent 走同一捷径说明是环境问题，要改规则而不是改单个 PR。

## 关键数字与案例

- 每月约 2,500 个 PR，平均一天 80 个（自述）。
- 十几个幕僚长，全自动验证对每个 PR 派验证小队（自述）。

## 待核验

- Dune、Bend、animatics 等名字是 ASR 听写。
