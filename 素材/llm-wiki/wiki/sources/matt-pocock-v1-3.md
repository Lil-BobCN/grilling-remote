## 一句话摘要

v1.3 的三个技能：implement-spec 用编排 agent 带 sub agent 跑完整个 spec；pr 用四栏让评审变便宜；retro 回读真实会话，找仓库和指令里的低效。

## 主要论点

- spec 是目的地，ticket 是会话；票之间有阻塞边，前沿票可以并行。
- 跑循环有三种方式：手动、脚本、agent 当保姆，可靠性依次不同。
- implement-spec 九步：读票、探索、建集成分支、逐票实现、合并、评审、清理、准备 PR。
- retro 只给建议，明确反对自动化。

## 关键数字与案例

- 九步流程；1.3.0 缺失、直接发 1.3.1（自述）。
