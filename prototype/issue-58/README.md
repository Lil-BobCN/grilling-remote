# 教程页新增一节：第一次对话会遇到什么（#58）

一句话：这是给教程页用的一节样品。客户看完，应该知道第一次对话分几步、自己每次要做什么。

## 怎么开

```bash
open prototype/issue-58/first-conversation.html
```

单文件，零依赖，浏览器直接开。手机宽度也能看。

## 这版定了什么（2026-11-07 运营者定）

1. 位置：说「开始需求澄清」之后，回传之前。
2. 内容：六步，加三件事总览、「继续」那一行和三忌。
3. 形式：纵向步骤，加一张 dsh 示意图。
4. 口径：保留 Agent 原话，教程不另写时间。

用词：教程页对客户不写「提示词②」，也不写「安装提示词」。只说「开始需求澄清」。客户包里的 `customer-kit/prompts/02-启动提示词.txt` 是启动句，不是安装步骤。

## 和原文对过的地方

- 第一段开场词整段引用，在第一步的 dsh 示意图里。
- 「已经确定需要拆分」「这件事不大，今天就能问清楚……」「终点是一句话」「拆完我把清单给你看……」逐句引用。
- 三忌按第二段原话，只把「一、二、三」换成列表序号，人称和句子没改。
- `继续：` 那一行按 `next` 的格式。例子用启动句文件里的 `tanxin-yuyue 01 空档怎么放`。

小需求那句「今天就能问清楚」保留，因为它是 Agent 的原话。它说的是这次对话，不是交付时间。教程不另加时间承诺。

## 没写

- 技能名、命令、交付时间、价格。
- 技术题「不懂就按推荐」那句。它归 #31 的整页提示，不在这节重复。
- 真实截图。示意图只表示位置，真截图归 #31 的截图清单。

## 范围

只做这一节，不重做整页。样式可以随 #31 改，文字和结构是这一版要定的。
