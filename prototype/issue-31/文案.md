## 首屏

- 小标题：客户使用教程 · 工作区 v1
- 主标题：三步装好，开口说你想做什么。
- 说明：这份教程带你把 DeepSeek Harness 和工作区准备好。装好之后，用日常的话跟它聊，它会把想法一步步问成一份能开工的需求。全程不用写代码。
- 主按钮：下载客户工作区（41,456 字节）
- 次按钮：下载 DeepSeek Harness
- 支持范围：支持 macOS（Apple 芯片 / Intel）和 Windows 64 位，不支持 Linux。需要一台能联网的电脑。
- 开始之前会用到的三样：DeepSeek Harness 桌面版（下面叫它 dsh）；客户工作区 v1（40.5 KB，技能和规则都在里面）；一个空文件夹（名字用日常中文，例如「需求澄清」）。
- 一句安心话：不用装命令行，不用 GitHub，也不用再装技能。

## 第 1 步：下载两样东西

客户看到：

> dsh 是打开工作区的工具，工作区包是给 dsh 读的规则和技能。两样都下好，再往下走。

| 卡片 | 文案 |
| --- | --- |
| 第一样：DeepSeek Harness 桌面版 | 到 DeepSeek 官网下载对应系统的安装包，按提示装好。文件名按系统对照：Windows 64 位 `dsh-latest-windows-x64.exe`；Mac Apple 芯片 `dsh-latest-macos-arm64.dmg`；Mac Intel 芯片 `dsh-latest-macos-x64.dmg`。不知道 Mac 是哪种芯片：苹果菜单 → 关于本机 → 看「芯片」。装完打开一次，能看到选择文件夹的界面就对了。安装时弹出安全提示，先截图找客服，不要自己关系统保护。 |
| 第二样：客户工作区 v1 | 这是给 dsh 用的工作区。九个技能、规则和说明都在里面，解压就能用，不用再装配。下载完，浏览器下载列表里应该看到 `客户工作区-v1.zip`。名字后面多一个 `.download`，说明还没下完。 |

「怎么确认文件没坏」折叠区：

- 双击能解压，解压后能看到 `AGENTS.md`，文件就没坏。打不开就重新下载。
- 需要精确核对时，用 SHA256：`ad5931acb522aa41d1a2d99173d8df45a99b5c60a29cc6bcdef44682ecc66105`。
- Mac 命令：`shasum -a 256 ~/Downloads/客户工作区-v1.zip`
- Windows 命令：`certutil -hashfile "%USERPROFILE%\Downloads\客户工作区-v1.zip" SHA256`

## 第 2 步：解压到一个空文件夹

客户看到：

> 工作区要单独放一个文件夹。以后每次都打开它，进度也存在里面。不要放进已有的代码项目，也不要和别的项目混在一起。

三个动作：

1. 新建空文件夹，名字用日常中文，例如「需求澄清」。路径里不要有奇怪符号，中文和空格没问题。
2. 把 zip 放进去，解压到当前文件夹。Mac 双击；Windows 右键 → 全部解压缩。
3. 打开文件夹，第一层要能直接看到 `AGENTS.md`。

对的样子：

```text
需求澄清/
├── AGENTS.md
├── README.txt
├── 技能清单.md
├── docs/
└── .dsh/
```

补一句：macOS 的 Finder 默认不显示 `.dsh`，按 `Cmd + Shift + .` 可以显示。

多套一层的样子：打开文件夹只看到一个文件夹，看不到 `AGENTS.md`。把里面的东西全部拖出来，放到当前文件夹。

一句硬规则：一个文件夹只做一个软件。要做第二个软件，重新下载一份最新版工作区，解压到新文件夹。这个包不自动升级。

## 第 3 步：用 dsh 打开，说第一句话

客户看到：

> 文件已经放好。打开 dsh，选中这个文件夹，说一句话就开始。

三个动作：

1. 打开 dsh，选择「需求澄清」文件夹。窗口里显示的路径应该就是这个文件夹。
2. 说第一句话。复制「开始需求澄清」，或者直接说想做什么，例如「我想做一个能预约的理发店小程序」。
3. 弹窗问权限就点允许。

Agent 会先检查三样文件在不在，然后讲一段话，再问你想做什么。一次只问一小轮。

自检没过的提示：

> 文件没放对，按官网第 2 步重放。

看到这句话，回到第 2 步看文件列表。不要重装，截这句话和文件列表找客服。

装好之后记住三件事：

1. 每次都打开这个文件夹。换文件夹，进度就没了。
2. 进度写在 `.scratch/` 里。不要自己改，想改什么直接跟 Agent 说。
3. 一个文件夹只做一个软件。第二个软件，另开一个文件夹。

## 第 4 节：第一次对话会遇到什么

开头：

> Agent 会先讲一遍接下来怎么走，再请你说想做什么。事情大，这一次会一直走到拆议题、排顺序。事情小，问完就结束。下面按大需求讲，一共六步；小需求在第 3 步分开。

两个提示：

- 先留意一句话：第一次打开时，Agent 会先检查工作区文件。如果它说「文件没放对，按官网第 2 步重放」，截这句话和文件列表，找客服，不要自己重装。
- 遇到完全不懂的技术题，直接说「这个我不懂」。要如实告诉 Agent，不然流程会在这里转不下去。它会按推荐答案往下问，并记下来，开工前有人跟你确认。

六步标题：

1. Agent 先讲一遍接下来怎么走
2. 你说想做什么
3. Agent 判断大小
4. 把终点定成一句话
5. 拆成一张一张议题
6. 看清单，定先做哪张

六步里的原话和「你要做」保留 `#58` 的写法，页面直接搬了那一节。

第一次对话结束：

> 定完顺序，Agent 会说一句「议题拆好了，顺序按你定的」，再请你新开一次对话。它给你一行字，原样复制过去，不要改。

示例：

```text
继续：tanxin-yuyue 01 空档怎么放
```

补一句：这是举例，每次的需求名、编号、票名都不一样，以 Agent 给你的那一行为准。

## 第 5 节：压缩整个文件夹，传回来

客户看到：

> 全部做完，Agent 会说「这件事都问完了」，不再推荐下一张票。接下来把整个工作区传回来，剩下的交给我们。

五个动作：

1. 压缩整个文件夹。Mac 右键文件夹 → 压缩「需求澄清」；Windows 右键 → 压缩为 ZIP 文件。压缩的是整个文件夹，不是只压 `.scratch/`。
2. 打开上传页 `https://upload.afkfactory.dev/`。
3. 登录。账号我们开通，密码通过微信发；忘了密码，找客服重设。
4. 拖入 zip，勾「已问完」。简称和邮箱由账号带出，不用填。
5. 提交，等我们联系。

必留一句：

> 文件夹里的所有文件都会上传，请只放本项目的资料。

补两句：对话记录不在这个文件夹里，不会跟着上传。整个压缩包控制在 50 MB 以内。

客户简称的解释：登录后由账号带出，不用填。客户简称是签约时给你的名字，不是需求名。拿不准就问客服。

## 客服区

- 通道：微信为主，电话兜底。
- 响应：有事先微信找我，我一般都在线；没回就是在忙或睡了，看到会回。
- 不设响应时限和紧急分级；客户不回不催，下次来接着聊。
