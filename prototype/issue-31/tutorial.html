客户使用教程 · 工作区 v1

三步装好，
开口说你想做什么。

这份教程带你把 DeepSeek Harness 和工作区准备好。装好之后，用日常的话跟它聊，它会把想法一步步问成一份能开工的需求。全程不用写代码。

下载客户工作区 41,461 字节 下载 DeepSeek Harness ↗

支持 macOS（Apple 芯片 / Intel）和 Windows 64 位，不支持 Linux。需要一台能联网的电脑。

开始之前，你会用到

  1. 1 DeepSeek Harness 桌面版 下面叫它 dsh。打开工作区、跟你对话的就是它。
  2. 2 客户工作区 v1 40.5 KB。技能和规则都在里面，解压就能用。
  3. 3 一个空文件夹 名字用日常中文，例如「需求澄清」。

不用装命令行，不用 GitHub，也不用再装技能。

安装 · 第 1 步

先下载，先别解压

下载两样东西

dsh 是打开工作区的工具，工作区包是给 dsh 读的规则和技能。两样都下好，再往下走。

第一样

DeepSeek Harness 桌面版

到 DeepSeek 官网下载对应系统的安装包，按提示装好。

打开官方下载页 ↗
Windows 64 位
dsh-latest-windows-x64.exe
Mac · Apple 芯片
dsh-latest-macos-arm64.dmg
Mac · Intel 芯片
dsh-latest-macos-x64.dmg

不知道 Mac 是哪种芯片：左上角苹果菜单 → 关于本机 → 看「芯片」那一行。装完先打开一次，能看到选择文件夹的界面，就说明装对了。安装时如果系统弹出安全提示，先截图找客服，不要自己关系统保护。

第二样

客户工作区 v1

这是给 dsh 用的工作区。九个技能、规则和说明都在里面，解压就能用，不用再装配。

下载 客户工作区-v1.zip

41,461 字节（40.5 KB）· 2026-11-07 版

下载完，浏览器下载列表里应该能看到 客户工作区-v1.zip。名字后面多一个 .download，说明还没下完，等一会儿再看。

怎么确认文件没坏

最简单的检查：双击能解压，解压后能看到 AGENTS.md，文件就没坏。打不开，就删掉重新下载一次。

要精确核对，把这个校验值和下载的文件对一下。这个值只给需要的时候用，平时不用管。

SHA256 49d3d89a8ccea55c76c19b84e1fbe6375d33b3d2a2f3fc9922a7533ae97038a6

Mac 在终端里跑：

shasum -a 256 ~/Downloads/客户工作区-v1.zip

Windows 在命令提示符里跑：

certutil -hashfile "%USERPROFILE%\Downloads\客户工作区-v1.zip" SHA256

算出来和上面的值一样，就没坏。对不上，先确认下的是最新版，再找客服。

安装 · 第 2 步

这一步最容易出错

解压到一个空文件夹

工作区要单独放一个文件夹。以后每次都打开它，进度也存在里面。不要放进已有的代码项目，也不要和别的项目混在一起。

  1. 1

    新建一个空文件夹

    名字用日常中文，例如「需求澄清」。放在你找得到的地方，桌面或文稿都行。

    路径里不要有奇怪符号。中文和空格没问题。

  2. 2

    把 zip 放进去，解压到当前文件夹

    Mac：双击 zip，系统会在旁边解压出一份。Windows：右键 zip → 全部解压缩，选这个空文件夹。

    不要在压缩软件里直接打开里面的文件，要先解压出来。

  3. 3

    看文件列表

    解压后打开文件夹，第一层就要能直接看到 AGENTS.md。看到它，就说明位置对了。

✓对的样子

需求澄清/
├── AGENTS.md
├── README.txt
├── 技能清单.md
├── docs/
└── .dsh/

看到 AGENTS.md 就对了。macOS 的 Finder 默认不显示 .dsh，按 Cmd + Shift + . 可以显示。以后打开的就是这个「需求澄清」文件夹。

一个文件夹只做一个软件。要做第二个软件，重新下载一份最新版工作区，解压到新文件夹。这个包不自动升级。

安装 · 第 3 步

到这一步就能开始聊了

用 dsh 打开，说第一句话

文件已经放好。打开 dsh，选中这个文件夹，说一句话就开始。

  1. 1

    打开 dsh，选择这个文件夹

    在 dsh 里打开「需求澄清」文件夹。窗口里显示的路径，应该就是你刚才那个文件夹。看不到路径，就重新选一次。

  2. 2

    说第一句话

    把下面这句复制过去，或者直接说你想做什么。

    开始需求澄清

    也可以直接说，例如「我想做一个能预约的理发店小程序」。Agent 会先判断这件事是大还是小。

    Agent 会先检查三样文件在不在，然后讲一段话，再问你想做什么。一次只问一小轮。

  3. 3

    弹窗问权限，就点允许

    它要写文件时，dsh 会弹窗问。点允许，它才能把进度写进文件夹。

如果它说「文件没放对，按官网第 2 步重放」：先回到第 2 步看文件列表。不要重装，截这句话和文件列表找客服。

装好之后，记住三件事

  1. 1

    每次都打开这个文件夹。换文件夹，进度就没了。

  2. 2

    进度写在 .scratch/ 里。不要自己改，想改什么直接跟 Agent 说。

  3. 3

    一个文件夹只做一个软件。第二个软件，另开一个文件夹。

开始之后 · 第 4 节

在 dsh 里

第一次对话会遇到什么

Agent 会先讲一遍接下来怎么走，再请你说想做什么。事情大，这一次会一直走到拆议题、排顺序。事情小，问完就结束。下面按大需求讲，一共六步；小需求在第 3 步分开。

先留意一句话。第一次打开时，Agent 会先检查工作区文件。如果它说「文件没放对，按官网第 2 步重放」，说明工作区文件没放对。截这句话和文件列表，找客服，不要自己重装。
遇到完全不懂的技术题，直接说「这个我不懂」。要如实告诉 Agent，不然流程会在这里转不下去。它会按推荐答案往下问，并记下来，开工前有人跟你确认。

大需求的六步里，你实际只做三件事

1说你想做什么 → 2回答 Agent 的问题 → 3看清单，定先做哪张

之后每次新对话，只多一件事：把 Agent 给的那一行原样复制过去。

  1. 1

    Agent 先讲一遍接下来怎么走

    它会告诉你：先说想做什么，它来判断大小；小的当场问清楚，大的拆成几次做。听完你直接说想法就行。

    需求澄清 · dsh示意图

    我先说说这件事接下来会怎么走。

    你先说你想做什么。我会判断这件事是大还是小。小的当场问清楚就完事了，之后会交给开发者；任务量大就需要拆分了，拆分成几个小任务，分几次做。

    你可以开始跟我说你模糊的想法了。

    用你自己的话说，想做什么…发送

    你要做听它讲完，直接说想法。

  2. 2

    你说想做什么

    用日常的话说，不用想术语，也不用一次说全。Agent 会从这段话判断事情大还是小。

    你要做说一段你想做的东西。

  3. 3

    Agent 判断大小

    它自己判断，不用你选。听完你的想法，它会说走哪条路。

    事情小

    「这件事不大，今天就能问清楚。问完我整理成一份需求草稿，交给开发去做。」

    接下来它问几轮，你回答。问完这次对话就结束，没有议题清单。

    事情大

    「已经确定需要拆分。」

    接着往下走，把终点定成一句话，再拆成议题。继续看第 4 步。

    你要做听它说走哪条，接着答。

  4. 4

    把终点定成一句话

    Agent 一轮列几个问题，每个都带推荐答案。你按自己的情况答。它把这些答案收成一句话，就是终点。

    拆的话，第一步是我跟你把它最后要做成什么样定下来。这就是终点。终点是一句话，比如「顾客在微信上看今天的水果、下单、选到店取还是送货，你在后台改价格和库存」。

    我问的问题请你自己答，一定要重视，因为问题和问题之间是有逻辑联系的，一步错，后面全跟着错。

    你要做自己答。一轮答不完就分几轮。

  5. 5

    拆成一张一张议题

    终点定下来，Agent 会先说「终点定了」，再把整件事拆成一张一张议题。一张议题就是一次对话，只定这一件事。

    接下来我把它拆成一张一张的议题，一张议题代表一个任务。这些任务都做完，你要的东西就做成了。

    你要做等它拆完。文件你不用打开，也不用管。

  6. 6

    看清单，定先做哪张

    拆完它把清单给你看：一共几张、每张做什么。顺序由你定。你说哪张先做，它就按你说的排。

    拆完我把清单给你看：一共几张、每张做什么、按什么顺序做。哪张要先做，你说，我按你说的排。

    每张开头还会写一句，这次是聊、看个样子、动手做，还是我去查。

    你要做看清单，说一句先做哪张。

第一次对话结束

之后每次新对话，只复制一行

定完顺序，Agent 会说一句「议题拆好了，顺序按你定的」，再请你新开一次对话。它给你一行字，原样复制过去，不要改。

继续：tanxin-yuyue 01 空档怎么放

这是举例。每次的「需求名、编号、票名」都不一样，以 Agent 给你的那一行为准，不要复制这里的例子。

Agent 会自己接上，不用你重新讲一遍。它会先说三句：这件事最后要做成什么、现在走到哪；已经定了几条；下一步做哪张。然后开始。

这个做法最怕的三件事

Agent 在拆议题前会提前说。记住这三句，后面会顺很多。

  1. 在一张议题里聊另一张的事。想到了就先说一声，我记到那张去，这张先做完。
  2. 说着说着拐到别处。拐了就拐了，你照说，我记下来，再拉回来。
  3. 在后面的议题里改前面定过的事。要改就说，我去改当初那一张，在地图上记一笔，不在新议题里悄悄改。

「进度我写在这个文件夹里，你不用打开，也不用改。想改什么直接跟我说。」

全部做完 · 第 5 节

最后一步

压缩整个文件夹，传回来

全部做完，Agent 会说「这件事都问完了」，不再推荐下一张票。接下来把整个工作区传回来，剩下的交给我们。

  1. 1

    压缩整个文件夹

    Mac：右键「需求澄清」文件夹 → 压缩「需求澄清」。Windows：右键文件夹 → 压缩为 ZIP 文件。

    压缩的是整个文件夹，不是只压 .scratch/。包里要带着 AGENTS.md 和 .scratch/。

  2. 2

    打开上传页

    上传页和教程页不在同一个地址。点下面这个按钮过去。

    打开上传页 ↗

  3. 3

    登录

    用我们发给你的邮箱和密码登录。账号由我们开通，密码通过微信发给你。

    忘了密码，找客服重设。

  4. 4

    拖入 zip，勾「已问完」

    把压缩包拖进上传框，勾上「已问完」。简称和邮箱由账号带出，不用填。

  5. 5

    提交，等我们联系

    看到上传成功就结束了。后面由我们处理，不用再操作。

文件夹里的所有文件都会上传，请只放本项目的资料。

对话记录不在这个文件夹里，不会跟着上传。整个压缩包控制在 50 MB 以内。
