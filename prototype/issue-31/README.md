# 教程页样品（#31）

一句话：给不会编程的客户看的教程页。单页往下走，三步装好，第 4 节看第一次对话，第 5 节把整个文件夹传回来。

## 怎么开

```bash
open prototype/issue-31/tutorial.html
```

单文件，零依赖，`file://` 直接开。手机宽度也能看。

## 运营者已定（2026-11-07）

1. **结构**：单页往下走，安装并成三步，第 4 节第一次对话，第 5 节回传。
2. **启动句**：第一句给复制按钮，第二句只给示例，不另做 `.txt`。
3. **Windows 口径**：页面只写「支持 Windows 64 位」，不写「还在实机验证」。实测记录留在 `customer-kit/测试记录.md` 和 #36。

## 这版定了什么

1. **单页，不分步翻页。** 左边目录跟着滚，手机上变成顶部横条。理由：客户会来回对照，客服话术按「第 N 步」指路，单页不用记路由；截图和打印也方便。
2. **安装三步：下载、解压、用 dsh 打开。** 客服版六步并成三步，其中解压是第 2 步。客户包 `AGENTS.md` 里写死了「按官网第 2 步重放」，所以这一步的编号不能改。
3. **首屏放标题、两个下载按钮、开始之前会用到的三样。** 两条路放在首屏下面单独一节，不混进下载按钮。
4. **下载不托管安装包。** 桌面版只给 DeepSeek 官网链接和文件名对照；工作区 zip 给直链、大小和折叠的 SHA256。
5. **第一句给复制按钮，第二句只给示例。** 「开始需求澄清」固定，放第 3 步，点一下复制。「继续：需求名 编号 票名」每次都不同，放第 4 节末尾，只给示例，不给复制按钮，免得客户把示例复制走。不做 `.txt` 下载：多一个文件容易丢，而且第二句是每次生成的。
6. **第一次对话整节并入 #58 的样品。** 六步、三件事总览、三忌、继续行都在，原话不改。
7. **回传写到上传成功。** 压缩整个文件夹 → 上传页 → 客户简称、邮箱、已问完 → 等联系。隐私提示用方案里的原句。上传页本身不做，只放入口。
8. **每一步都有找客服入口。** 一句话话术加复制按钮，底部客服区只放扫码位和「找签约对接人」。
9. **两条路分开放。** 不会编程走工作区 zip；会编程走 `mattpocock/skills` 原版。文案不写「客户不接触 GitHub」。
10. **八张图先用示意图占位。** 真图和拍摄要求见 `截图清单.md`。

## 哪些是模拟的

- 八张图是 CSS 画的示意图，不是真截图。
- 客服二维码是虚线框，没有真码。
- 上传页是线框，上传地址还没上线。点「打开上传页」现在打不开，或者返回占位内容。
- 复制按钮优先走 `navigator.clipboard`，浏览器不支持时退回 `execCommand`。系统问剪贴板权限时要点允许。
- 页面不发请求，不收集任何数据。

## 范围

## 自测

- 1440、1024、390 三档：`scrollWidth == clientWidth`，没有横向滚动。
- 八个截图位、目录锚点都能跳，6 个复制按钮，控制台 0 报错。
- 真实点击「开始需求澄清」的复制按钮：`file://` 和本地 HTTP 下剪贴板都读到「开始需求澄清」，按钮显示「已复制」。
- 目录高亮、锚点跳转、SHA256 折叠区、键盘焦点都过了一遍。
- 打印样式隐藏了导航、样品条和复制按钮。
