SHA256 和怎么核对

SHA256 给客服核对文件用，客户平时不用管。下载完不放心，可以按下面的命令算一遍，和这个值对得上就没坏。

ad5931acb522aa41d1a2d99173d8df45a99b5c60a29cc6bcdef44682ecc66105

Mac 在终端里跑：

shasum -a 256 ~/Downloads/客户工作区-v1.zip

Windows 在命令提示符里跑：

certutil -hashfile "%USERPROFILE%\Downloads\客户工作区-v1.zip" SHA256

对不上，先确认下的是最新版，再找客服。

支持 macOS（Apple 芯片 / Intel）和 Windows 64 位，不支持 Linux。下载列表里文件名后面多一个 .download，说明还没下完。

打开工作区的工具：dsh

DeepSeek Harness 桌面版，下面叫它 dsh。工作区是给它读的规则和技能；dsh 是打开工作区、跟你对话的那个窗口。

DSH
DeepSeek Harness 桌面版

到 DeepSeek 官网下载对应系统的安装包，按提示装好。装完先打开一次，能看到选择文件夹的界面，就说明装对了。

Windows 64 位

Mac · Apple 芯片
dsh-latest-macos-arm64.dmg
Mac · Intel 芯片
dsh-latest-macos-x64.dmg

不知道 Mac 是哪种芯片：左上角苹果菜单 → 关于本机 → 看「芯片」那一行。安装时系统弹出安全提示，先截图找客服，不要自己关系统保护。

三步装好

按顺序走。第 2 步有一个肉眼检查，看到 AGENTS.md 才算对。

01

下载两样

先下工作区 zip，再下 dsh 的安装包。两个都下好，再往下走。

02

解压到空文件夹

新建一个空文件夹，名字用日常中文，例如「需求澄清」。把 zip 放进去，解压到当前文件夹。

检查：文件列表里直接看到 AGENTS.md。只看到一个同名文件夹，就是多套了一层。
03

用 dsh 打开并开口

在 dsh 里选这个文件夹，然后说一句「开始需求澄清」。它会先自检，再问你想做什么。

看完整教程（含截图） → 每一步卡住，都有截图和客服话术。

不会写代码，走这条就对了
