# 官网下载页、清单页、上传页样品（#208）

> 2026-11-14 起本目录是历史样品，已废弃。当前技能数和版本数据以 `customer-kit/manifest.json` 和 `customer-kit/release.json` 为准。

一句话：三个单文件样品，定官网下载页、技能清单页、上传页的样子和文案位置。视觉跟教程页（`prototype/issue-31/tutorial.html`）同一套。

## 怎么开

```bash
open prototype/issue-208/index.html
```

- 三页互相有顶栏链接：下载 / 技能清单 / 教程 / 上传 / 我的订单。
- 教程链接到已有样品 `prototype/issue-31/tutorial.html`；「我的订单」链接到已有样品 `prototype/issue-109/index.html`。
- 零依赖，`file://` 直接开。手机宽度也能看。

## 三页各定了什么

| 页 | 文件 | 定下的内容 |
| --- | --- | --- |
| 下载页 | `index.html` | 下载按钮、文件名、版本、日期、大小、SHA256（折叠，给客服核对）。另放 dsh 下载入口和三步装法。 |
| 清单页 | `skills.html` | 九个技能，一行一个：名字、一句话、什么时候用。不做勾选，不让客户挑。 |
| 上传页 | `upload.html` | 登录后上传：简称和邮箱由账号带出；拖入 zip；勾「已问完」；隐私提示；50 MB 上限；上传成功状态。 |

## 数据从哪来

- 工作区版本、日期、大小、SHA256、下载地址：`customer-kit/README.md` 记的第三次构建（#113 发布用）。`41,456` 字节，`2026-11-07`。
- 九个技能：`customer-kit/manifest.json` 的 v1 快照，顺序和原文照抄。
- 上传页字段和文案：`docs/客户工作区方案.md` 第六、七节，`docs/客户进度.md`，`docs/服务器操作手册.md` 的上传体积上限一节。
- 上传页的「已问完」和隐私提示原句：「文件夹里的所有文件都会上传，请只放本项目的资料。」

## 哪些是模拟的

- 上传不会真的发出去。点「上传」只走一段假的上传动画，显示成功状态。
- 账号是演示账号：王秀兰 / `wangxiulan@example.com`。简称和邮箱只作展示，不对接登录。
- 上传页顶部深色样品条里三个按钮可以试状态：正常包、超限包、不是 zip。正式页删掉。
- 清单页的数据是抄进 HTML 的快照。正式站上由构建脚本从 `manifest.json` 生成，页面不手写。
- 下载页的下载链接是真的，指向已发布的 `客户工作区-v1.zip`。SHA256 折叠区和复制按钮可用。
- 三页都没有后端请求，不收集数据。

## 边界和前提

- 只做三页的样子和文案位置。上传页的登录、接收端点、建仓建单归 to-spec，不在本票。
- 不改教程页，也不动 `site/`。现在仓库里还没有 `site/` 目录。
- **清单独立成页。** `docs/客户工作区改版简报.md` 原写官网「一页三块：下载按钮、技能清单、三步图」。本票按三页拆；下载页保留三步装法。如果运营者要一页三块，把清单并回下载页即可。
- 下载页的三步装法来自 `docs/客户工作区方案.md` 第七节「三步图」。教程页有完整版，下载页只放压缩版并链过去。
- 上传页只展示登录后的状态。登录页本身在 `prototype/issue-109/index.html` 里，不在这三页里重做。

## 这一轮按 impeccable 清单改了什么

用 impeccable 的反模式清单和三页检测器过了一遍，改了两轮：

- 去掉所有左侧色条（`border-left` 3px 的提示块），改成整圈细边框加浅底色。
- 拆掉卡片套卡片：下载页右侧文件栏改成带分隔线的栏，三步改成三栏加分隔线；上传页合成一张工作区卡片，右栏用分隔线分三段。
- 去掉标题上方的小标签（hero eyebrow）和每节重复的小标签，标题直接进正文。
- 顶栏去掉毛玻璃，改成实色。
- 上传页的选文件区从 `label` 改成 `button`，键盘能 Tab 到、回车能打开文件选择；成功状态自动接收焦点。
- 移动端导航、上传按钮、换文件按钮、复制按钮都补到 44px 高。
- 对比度：页脚、品牌副标题、技能编号改用更深的灰；禁用按钮改成浅底深字。
- 文案去重：删掉重复的「不会写代码」和隐私说明。

检测器结果：`side-tab` 从 10 条降到 0；`single-font` 剩 3 条，是误报，检测器不解析 CSS 变量，浏览器里核过标题、正文、代码用了三套字体。

## 2026-11-13 第二轮（impeccable 4.9.0）

检测器换成新版，命令是 `impeccable detect`。这一轮按结果改了三处：

- 下载页 SHA256 和两条核对命令从 11.5px 提到 12.5px；dsh 三个安装包文件名从 11px 提到 12.5px。
- `cramped-padding` 两条是误报。检测器把 `li:first-child{padding-top:0}` 套到了全部列表项，以为所有行都贴着分隔线。浏览器实测非首行上内边距是 12px（下载页）和 10px（上传页）。CSS 改成 `li + li` 写法，误报消失，渲染不变。
- `cream-palette` 三条保留。三页和教程页、订单页共用同一套暖纸底色（`--bg:#f2eee3`），这是已经定下的视觉世界。只换这三页会跟视觉基准脱节；要换就四个样品一起换，另开票。

## 自测

- 三页分别用浏览器打开，1440、1024、390 三档无横向滚动，控制台 0 报错。
- 下载页：SHA256 复制按钮可点；折叠区能展开；dsh 和教程链接可达。
- 清单页：九行齐全，和 `customer-kit/manifest.json` 对上。
- 上传页：
  - 键盘 Tab 到选文件按钮，回车能打开文件选择；选一个 zip 后显示文件名和大小。
  - 勾「已问完」后「上传」才可点。
  - 点「正常包」：填入 11.8 MB 的假文件；点「超限包」：出现「超过 50 MB 上限」；点「不是 zip」：出现「只收 .zip」。
  - 点「上传」：进入成功状态，焦点落在成功面板；点「再传一个」回到空表单，焦点回到选文件按钮。
  - 移动端 390：导航、上传、换文件、勾选区的点击高度都不小于 44px。

- 2026-11-13 复测：`test2.js` 跑完 1440 / 1024 / 390 三档 9 个组合，无横向滚动、控制台 0 报错；上传页键盘选文件、超限、非 zip、提交、成功、重置全过。`test3.js` 的 SHA256 复制通过。

## 还没定

1. **品牌名。** 顶栏现在用「AF / 需求澄清」，教程页也是这个。要换公司名或加 logo，说一声。
2. **上传页的「我的订单」入口。** 现在指向 #109 样品。真实地址等进度模块上线再换。
3. **清单页的生成方式。** 现在是快照。正式站是按 `manifest.json` 构建时生成，还是运行时读 JSON，归 to-spec。
4. **下载页要不要二维码或客服入口。** 教程页有客服区；下载页现在只留一句「卡住了找客服」。要不要在下载页也放二维码，等运营者定。
5. **三页的正式路由。** 现在是 `index.html`、`skills.html`、`upload.html`。上线时按 `site/` 的目录结构改。
