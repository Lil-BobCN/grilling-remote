客户工作区 v1
2026-11-07

这是给 DeepSeek Harness（dsh）用的需求澄清工作区。解压后，这个文件夹就是工作区，不用装配。

包含：
- AGENTS.md：工作区规则，dsh 每次打开都会读
- docs/agents/：两份说明文件
- .dsh/skills/：九个技能。名字以点开头，系统可能默认不显示
- 技能清单.md：九个技能各管什么，什么时候用
- LICENSE：上游技能的 MIT 许可证
- NOTICE.md：上游来源和改动说明
- README.txt：本文件

使用：
1. 新建一个空文件夹，把 zip 放进去，解压到当前文件夹。
2. 解压后，文件列表里要能直接看到 AGENTS.md。只看到一个文件夹，说明多套了一层。把里面的东西拖出来。
3. 用 dsh 打开这个文件夹，说“开始需求澄清”，或直接说你想做什么。
4. 之后每次新开对话，把收尾时 agent 给你的那一行原样复制发出去。

注意：
- 每次都打开同一个文件夹。换文件夹，进度就没了。
- 进度都记在 .scratch/ 里。不要自己改，要改就告诉 agent。
- 不要改 AGENTS.md、docs/、.dsh/ 里的文件。
- 一个文件夹只做一个软件。要做另一个软件，再解压一份到新文件夹。
- 以点开头的文件夹，Mac 的 Finder 里按 Cmd+Shift+. 可以显示。
- 全部做完后，agent 先核一遍文件，再提醒你压缩整个文件夹，到官网上传页上传。文件夹里的所有文件都会上传，请只放本项目的资料。
- 支持 Windows 64 位、macOS Apple 芯片、macOS Intel。不支持 Linux。
