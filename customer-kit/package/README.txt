grilling-skills 技能包 v1
2026-11-05

这是给 DeepSeek Harness（dsh）用的需求澄清技能包。

包含：
- skills/：八个技能
- AGENTS-TEMPLATE.md：工作区规则模板
- LICENSE：上游技能的 MIT 许可证
- NOTICE.md：上游来源和改动说明
- README.txt：本文件

安装：
1. 把 grilling-skills-v1.zip 拖进你要用的工作文件夹。
2. 用 dsh 打开这个文件夹。
3. 粘贴官网上的“装配提示词”。

注意：
- 技能装到工作文件夹的 .dsh/skills/。
- 换文件夹技能就没了，每次都打开同一个文件夹。
- 装完关掉 dsh 再打开。
- 不要改 skills/ 里的文件。
- 支持 Windows 64 位、macOS Apple 芯片、macOS Intel。不支持 Linux。
- Windows 未实机验证。
