# 客户安装步骤（客服版）

一句话：客服只做三件事。让客户确认装的是官网桌面版；让客户把工作区 zip 解压到空文件夹；用 dsh 打开并说一句话。卡住就要卡住那一步的截图。

## 两条路线

- 不会编程的客户：下载官网工作区 zip，按这份步骤做。
- 会编程的客户：直接用 `mattpocock/skills` 官方仓库的原版技能包，不走这份安装步骤。

## 支持范围

- Windows 64 位
- macOS Apple 芯片
- macOS Intel
- 不支持 Linux
- 桌面版自带 Node，客户不用装命令行环境

Windows 没有实机测过，标“未验证”，归 #36 实测。Windows 解压、中文路径、`.dsh` 被隐藏时 dsh 是否正常，也未验证，归 #36。

## 步骤和检查

| 步骤 | 客户做什么 | 客服检查什么 |
| --- | --- | --- |
| 1 | 打开官网 `https://www.deepseek.com/harness`，下载对应系统的桌面版 | 文件名对得上：`dsh-latest-windows-x64.exe`、`dsh-latest-macos-arm64.dmg` 或 `dsh-latest-macos-x64.dmg` |
| 2 | 安装并打开 dsh | 应用能打开，能看到选择文件夹的界面 |
| 3 | 从 #35 发布的官网地址下载 `客户工作区-v1.zip` | 文件名完整，下载已完成 |
| 4 | 新建一个空文件夹，名字用日常中文，例如“需求澄清”。不要放进已有的代码项目里。把 zip 放进去，解压到当前文件夹 | 文件夹路径里没有奇怪的符号，客户记得住位置；文件夹里没有 `.git`；解压前文件夹是空的；解压后文件列表里直接能看到 `AGENTS.md`。只看到一个文件夹，就是多套了一层 |
| 5 | 用 dsh 打开这个文件夹 | dsh 窗口显示的路径就是这个文件夹 |
| 6 | 第一次说“开始需求澄清”，或直接说“我想做一个……”。之后每次新开对话，原样复制 Agent 收尾给的那一行，形如“继续：tanxin-yuyue 01 空档怎么放” | Agent 先自检，通过后讲第一段开场词，再问“你想做什么？”，一次只问一小轮。续做时 Agent 直接做需求名和编号对应的那张票（新会话只发“继续：需求名 编号 票名”能否接上，未验证） |

## 每一步的失败信号

- 第 1 步：官网打不开，或者下载页没有对应系统的按钮。让客户截图下载页，客服发直链。
- 第 2 步：安装包打不开，或系统提示“无法验证开发者”。让客户截图提示框，按系统版本给放行步骤。
- 第 3 步：zip 下不下来，或文件名变成 `客户工作区-v1.zip.download`。让客户等下载完再用。
- 第 4 步，多套一层文件夹：解压后文件列表里看不到 `AGENTS.md`，只看到一个同名文件夹。让客户把里面的东西拖出来，再截一张文件列表给客服。没有兜底提示词，靠这一步的肉眼检查和客服。
- 第 4 步，没解压：文件夹里只有 zip，没有 `AGENTS.md` 和 `.dsh`。让客户把 zip 解压到当前文件夹，按系统版本给解压方法。
- 第 4 步，`.dsh` 被隐藏：文件列表里能看到 `AGENTS.md`，看不到 `.dsh`。系统或解压工具可能把点开头的文件夹藏起来了。先别让客户重解压，让客户打开系统的“显示隐藏文件”再看一眼，看到 `.dsh/skills/` 才算对。`.dsh` 被隐藏时 dsh 能不能正常读到技能，未验证，归 #36。
- 第 5 步，以及之后每次新开对话：看不到刚才的文件，或 Agent 找不到票。先确认打开的是同一个文件夹。技能跟着文件夹走，换文件夹就没了。
- 第 6 步：Agent 说“文件没放对，按官网第 2 步重放”，然后停下，不问需求。这是自检没过，缺 `docs/agents/issue-tracker.md`、`docs/agents/domain.md`、`.dsh/skills/` 里的一个。官网第 2 步就是这里的第 4 步。让客户截 Agent 的话和文件列表，回头查第 4 步。
- 第 6 步：Agent 没有自检，也没讲开场词。说明读不到 `AGENTS.md`，先查是不是多套一层或没解压，回看第 4 步的文件列表。
- 第 6 步：Agent 说没有权限写文件。这是 dsh 的批准弹窗，让客户点允许；截弹窗给客服看。
- 第 6 步：Agent 报某个技能不在。让客户把 Agent 的报错原文截给客服，不要自己重装。

## 首单实测（运营者做，客户不用做）

第一个客户解压并打开后，在同一个会话里测两件事，结果记进 `测试记录.md`。

1. 让 Agent 说出它有没有 `subagent` 和 `subagent_fork` 两个工具。少一个，就改 `map-gate`、`wrap-up` 里起子代理的写法。
2. 让 Agent 用命令行工具试 `dsh --version`。能跑就记下版本号，跑不了记“没拿到”，不要让客户自己找命令行。

依据：本机 dsh 0.2.1-rc.5 有这两个工具，客户机版本没测过。见 `docs/工厂流程.md` 里「派子代理时要求新上下文窗口」那一行。

## 装完要交代客户的三句话

1. 每次都打开这个文件夹，不要换。
2. 进度都在 `.scratch/` 里，不要自己改；要改就告诉 Agent。
3. 一个文件夹只做一个软件。要做另一个软件，再解压一份到新文件夹。

## 做完后回传

全部做完，Agent 会提醒客户：压缩整个文件夹，到官网上传页拖入，填客户简称和邮箱，勾“已问完”。

- 文件夹里的所有文件都会上传，让客户只放本项目的资料。
- 对话记录在 `~/.dsh/sessions/`，不在工作区里，v1 不回传。
- Mac 和 Windows 右键压缩是否带上隐藏的 `.scratch/` 和 `.dsh`：未验证，归 #36。
- 上传页和接收端点还没建，归后续 `to-spec`。

## 客服一句话版

“先确认你装的是官网的 DeepSeek Harness。新建一个空文件夹，把工作区 zip 放进去，解压到当前文件夹，看到 `AGENTS.md` 就对了。再用 dsh 打开这个文件夹，说一句「开始需求澄清」。哪一步卡住，就把那一步的屏幕截图发我。”

## 客服带话（运营者改了推荐答案之后）

触发：运营者在 `pending.md` 里改了某条推荐答案，或要向客户补问一个业务事实。

通道：微信为主，电话兜底。签约时登记对接人微信；邮件只用来发文件。

话术三段，一次说完，总共不超过 100 字：

1. 说清来意：“X 总，上次那个需求里有一步技术选择，我们这边定了。”
2. 说结论和对客户的影响：“后端用 A，您不用操作，也不会多花钱。”
3. 只问一个问题：“您确认一句，这样行不行？”

客户答完，客服回一句“收到，我记下了”。把客户原话抄进运营者这边的 `pending.md` 条目，写日期。不要求客户重开 `dsh`，也不要求客户自己改文件。

抄完之后，运营者跑一次 `/question-tree <需求目录>`，看这份需求的问题树三堆。客户认可运营者改后的答案，走第 5 步：运营者明确说核实通过，才记一行“核实，未改答案”。客户不同意，把客户的答案当新答案，走第 3 步，沿依赖边重算下游。

## 客户怎么看 `.scratch/` 文件

客户不用自己编辑。`.scratch/` 要等客户第一次说需求，Agent 才会建。文件夹名以点开头，Mac 的 Finder 默认看不见，按 Cmd+Shift+. 可以显示。Windows 资源管理器里是否默认可见，未验证，归 #36。要看内容，就让 dsh 读给客户听，或让 dsh 打开对应文件。不要手动改，改了 Agent 可能读不到。
