# 客户安装步骤（客服版）

一句话：客服只做三件事。让客户确认装的是官网桌面版；把 zip 拖进工作文件夹；粘贴提示词①。卡住就要卡住那一步的截图。

## 两条路线

- 不会编程的客户：下载官网技能包，按这份步骤装。
- 会编程的客户：直接用 `mattpocock/skills` 官方仓库的原版技能包，不走这份安装步骤。

## 支持范围

- Windows 64 位
- macOS Apple 芯片
- macOS Intel
- 不支持 Linux
- 桌面版自带 Node，客户不用装命令行环境

Windows 没有实机测过，标“未验证”，归 #36 实测。

## 步骤和检查

| 步骤 | 客户做什么 | 客服检查什么 |
| --- | --- | --- |
| 1 | 打开官网 `https://www.deepseek.com/harness`，下载对应系统的桌面版 | 文件名对得上：`dsh-latest-windows-x64.exe`、`dsh-latest-macos-arm64.dmg` 或 `dsh-latest-macos-x64.dmg` |
| 2 | 安装并打开 dsh | 应用能打开，能看到选择文件夹的界面 |
| 3 | 新建一个工作文件夹，名字用日常中文，例如“需求澄清”。不要放进已有的代码项目里 | 文件夹路径里没有奇怪的符号，客户记得住位置；文件夹里没有 `.git` |
| 4 | 从 #35 发布的官网地址下载 `grilling-skills-v1.zip`，拖进这个文件夹 | 文件夹里能看到 zip，文件名完整 |
| 5 | 用 dsh 打开这个工作文件夹 | dsh 窗口显示的路径就是这个文件夹 |
| 6 | 粘贴提示词①，等它做完 | Agent 报五项都在：八个技能、`AGENTS.md`、两个 `docs/agents/` 文件、`.scratch/` |
| 7 | 完全退出 dsh，再打开，重新打开同一个文件夹 | 重开后还能看到刚才那些文件 |
| 8 | 输入提示词②：新需求输“开始需求澄清”，同一需求续做输“继续” | Agent 先问“你想做什么？”，一次只问一小轮 |

## 每一步的失败信号

- 第 1 步：官网打不开，或者下载页没有对应系统的按钮。让客户截图下载页，客服发直链。
- 第 2 步：安装包打不开，或系统提示“无法验证开发者”。让客户截图提示框，按系统版本给放行步骤。
- 第 4 步：zip 拖不进去，或文件名变成 `grilling-skills-v1.zip.download`。让客户等下载完再拖。
- 第 6 步：Agent 说找不到 zip。让客户确认 zip 就在当前文件夹根目录，不在子文件夹里。
- 第 6 步：Agent 说没有权限解压或写文件。这是 dsh 的批准弹窗，让客户点允许；截弹窗给客服看。
- 第 6 步：Agent 报某个技能不在。让客户把 Agent 的报错原文截给客服，不要自己重装。
- 第 7 步：重开后文件不见了。先确认打开的是同一个文件夹。技能跟着文件夹走，换文件夹就没了。

## 首单实测（运营者做，客户不用做）

第一个客户装完后，在同一个会话里测两件事，结果记进 `测试记录.md`。

1. 让 Agent 说出它有没有 `subagent` 和 `subagent_fork` 两个工具。少一个，就改 `AGENTS-TEMPLATE.md` 里查漏的写法。
2. 让 Agent 用命令行工具试 `dsh --version`。能跑就记下版本号，跑不了记“没拿到”，不要让客户自己找命令行。

依据：本机 dsh 0.2.1-rc.5 有这两个工具，客户机版本没测过。见 `docs/工厂流程.md` 里「派子代理时要求新上下文窗口」那一行。

## 装完要交代客户的三句话

1. 每次都打开这个文件夹，不要换。
2. 进度都在 `.scratch/` 里，不要自己改；要改就告诉 Agent。
3. 装完或换文件夹后，关掉 dsh 再打开。

## 客服一句话版

“先确认你装的是官网的 DeepSeek Harness。新建一个文件夹，把技能包 zip 拖进去，用 dsh 打开这个文件夹，粘贴第一条提示词。它说五项都齐了，就退出重开，再粘贴第二条。哪一步卡住，就把那一步的屏幕截图发我。”

## 客服带话（运营者改了推荐答案之后）

触发：运营者在 `pending.md` 里改了某条推荐答案，或要向客户补问一个业务事实。

通道：微信为主，电话兜底。签约时登记对接人微信；邮件只用来发文件。

话术三段，一次说完，总共不超过 100 字：

1. 说清来意：“X 总，上次那个需求里有一步技术选择，我们这边定了。”
2. 说结论和对客户的影响：“后端用 A，您不用操作，也不会多花钱。”
3. 只问一个问题：“您确认一句，这样行不行？”

客户答完，客服回一句“收到，我记下了”。把客户原话抄进运营者这边的 `pending.md` 条目，写日期。不要求客户重开 `dsh`，也不要求客户自己改文件。

## 客户怎么看 `.scratch/` 文件

客户不用自己编辑。用 Finder（Mac）或资源管理器（Windows）打开工作文件夹，能看到 `.scratch/`。要看内容，就让 dsh 读给客户听，或让 dsh 打开对应文件。不要手动改，改了 Agent 可能读不到。
