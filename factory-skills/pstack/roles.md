# 角色表

结论：每个角色的 agent 和模型都还没定，所有格子写「待定」。技能读这份文件找模型。没配置时，用父会话的模型。

本表对应 `docs/流程 v4.md` 第八节。第八节的 10 个角色全部在下面。

## 怎么读

1. 技能里写「读 `roles.md` 里的某一行」。行名在第一列。
2. 找到这一行。agent 和模型两格是「待定」或者空，就用父会话的模型。
3. 一行填了多个模型，表示这个角色每个模型各跑一份。
4. 这份文件不写任何模型名。要填的人在这里填。
