**冒头**：
谈话中冒出来、还没落到票或地图里的新需求。先记一条，会话结束前由运营者判去向。
_Avoid_: 临时需求、插入需求

**决定**：
一条由关票定下的结论，有唯一编号（形如 `D-0002`）。写一次，写在关闭票评论的表里，别处只读不写。
_Avoid_: 决策、决定项、决议

**扫描表**：
关闭一张票前，贴在这张票上的评论，是决定的唯一写入点。正文是一张表：一行一条决定，列固定为 `id`、`决定`、`取代`、`解答未定`、`产出文件`。
_Avoid_: 影响分析、检查单

**台账**：
`docs/decisions.md`，只收现行决定，按编号排列。由 `scripts/decisions build` 生成后提交进 git，禁止手改。被取代的条目不放这里，进 `docs/decisions-archive.md`。
_Avoid_: 决定清单、清单文件

**现行决定**：
台账的行，是 `to-spec` 读的现行决定之一。`to-spec` 还读地图全文，需要细节时打开台账里这条决定对应的来源票；地图 `Decisions so far` 只当索引。台账不是唯一输入。
_Avoid_: 最新决定

**被取代**：
被后来的决定推翻的决定。编号和原行从台账挪进 `docs/decisions-archive.md`，原样保留，历史不删。ADR 整份被取代的直接删，靠 git 历史找回；部分被取代的保留，开头指向新 ADR。
_Avoid_: 已废、删除、过期

**依据**：
开放票正文第一行的那句 `依据：D-0002,D-0005`，列出这张票动手前认定仍然有效的决定编号。不依赖任何已定决定时写 `依据：无`。
_Avoid_: 依赖、引用、前提

**推迟**：
决定里写明以后再做的那一部分，和「决定」那一句写在同一行。下游读到它，知道这条决定没覆盖到那里，不当成已经做完。
_Avoid_: 遗留、TODO、后续工作
