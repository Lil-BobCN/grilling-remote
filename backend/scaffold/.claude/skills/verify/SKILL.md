# 验证应用

## 什么时候用

改了顾客能看到的行为，合并前跑一次。只改文档、只改内部实现不用跑。

## 怎么跑

在仓库根目录执行：

```bash
bash scripts/verify.sh
```

脚本做三件事：启动应用、填手机号下一单、把确认页截图到 `.audit/screenshots/first-order.png`。

默认端口 4317。端口被占用时换一个：

```bash
PORT=4318 bash scripts/verify.sh
```

## 跑完看什么

1. 终端输出「关键路径通过」和截图路径。
2. 打开截图，确认是确认页，上面有「订好了」、取货时间和单号。
3. 脚本报错时先看是哪一步：应用没起来、下单没跳转、确认页内容不对。

## 没有 Chrome

脚本会跳过截图并打印说明。关键路径仍然验证过。截图这一项记进 PR 证据，写明「本机没有 Chrome」。

## 功能地图

应用有哪些功能、顾客从哪进，见 `docs/agents/feature-map.md`。改到哪块，就在 PR 里说明这次验证覆盖了地图上的哪一行。
