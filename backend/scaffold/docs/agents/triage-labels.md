# 分类标签

五个 triage 标签和四个状态标签已经在 GitHub 上建好。这里是它们的含义。

| 标签 | 颜色 | 含义 |
| --- | --- | --- |
| `needs-triage` | `#d4c5f9` | 需要判断怎么处理 |
| `needs-info` | `#fbca04` | 等待补充信息 |
| `ready-for-agent` | `#0e8a16` | 信息完整，可以交给 agent |
| `ready-for-human` | `#1d76db` | 需要人处理或作出决定 |
| `wontfix` | `#ffffff` | 确定不处理 |
| `状态:已提交` | `#ededed` | 已建单，等技术闸门 |
| `状态:排队中` | `#fbca04` | 轮到了，等点火 |
| `状态:开发中` | `#1d76db` | 正在跑 |
| `状态:待验收` | `#0e8a16` | 活干完了，等验收 |

- 其他文档提到处理状态时，用表里的标签名，不改写、不翻译。
- 状态标签只由自动化改，agent 不贴、不摘。
- 缺标签时找维护者，不要在仓库里新建。
